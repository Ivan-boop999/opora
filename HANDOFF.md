## Что реализовано (2026-09-22, конец дня)

**Бэкенд** (все данные реально сохраняются в Postgres):
- Telegram-вход: серверная проверка подписи initData (HMAC, срок 24 ч), upsert пользователя, cookie-сессия шаблона. Тесты: валидная/поддельная подпись, чужой бот, просрочка.
- Отметки состояния: настроение/энергия/напряжение 1–5 независимо + эмоции/контекст/потребность/заметка; несколько в день; правка/удаление.
- Рекомендации: детерминированный движок правил (`rules-v1`) с объяснимой причиной; фильтры исключений/ограничений/времени; альтернативы. Тесты.
- Каталог: 48 карточек (задание §21, каждая с шагами и облегчением), поиск (без учёта регистра/ё), фильтры, избранное, исключения, версии.
- Сессии практик: start→complete/partial/skipped, идемпотентное завершение (повтор не начисляет дважды), обратная связь (пробовал/эффект/посильность).
- Сад: SVG-сцена (3 варианта света, 6 видов растений × 5 стадий), капли заботы с лимитом 4/сутки по локальному дню, журнал начислений с уникальным основанием, рост по накопительным порогам, разблокировка видов, ачивки. Тесты инвариантов.
- План: личные опоры (рутины) с расписанием и отметками done/partial/moved/skipped.
- Программы: 8 штук по заданию §22 с полным содержанием дней, запись/пауза/возобновление/бросание, лог дней, автопродвижение.
- Фокус: намерение, длительность, пауза/продолжение, elapsed считается по wall-clock отметкам на сервере (не setInterval).
- Сон: субъективное качество + времена за дату.
- Дневник: создание/правка (optimistic concurrency через editVersion)/удаление/удаление всех, теги, поиск, черновики.
- Обзор «Сегодня»: агрегат одного запроса (отметка, рекомендация, опоры, программа, сад, избранное).
- Статистика: периоды 7/30/90/всё, средние по шкалам, динамика, топ практик, эффекты, осторожные наблюдения (порог ≥5 оценок в ≥3 днях), сон, недельный блок.
- Поддержка: честные ресурсы по странам (пока ничего не опубликовано — только черновик RU 112 для проверки владельцем), раздел «Нужна поддержка» с 5 дорожками.
- Преференции/согласия: тема, TZ, страна, ограничения, видимость игры, onboarding-статус.

**Фронтенд**: палитра «тихой оранжереи» (светлая/тёмная, Manrope с кириллицей, self-hosted), оболочка с 5 вкладками (нижняя навигация мобайл/сайдбар ПК), онбординг из 5 экранов, «Сегодня», каталог + экран практики с режимом «проще» и опросом после, сад (SVG, коллекция, сцены), дневник, «Я» (тема/TZ/страна/переключатели/удаление дневника), поддержка, фокус-таймер, программы, наблюдения. Telegram SDK: ready/expand/хаптика/back button/safe-area; браузерный вход — запасной путь.

**Проверки**: backend typecheck ✓, unit 320/320 ✓, webapp typecheck+build ✓, webapp tests 71/71 ✓, architecture:check ✓, template:check ✓. Локальный smoke ✓. Прод: миграции+seed применены, health 200, CORS/подпись initData проверены.

## Ключевые решения (почему так)

- Пользователь Telegram = synthetic email `<tg-id>@telegram.opora` (пароль-флоу шаблона не тронут).
- День наград = локальная дата в TZ пользователя на момент записи (смена TZ не переписывает историю; кап остаётся ограниченным).
- 48 карточек засеяны `published` по редакционному плану владельца из задания; sourceNotes каждой карточки честно фиксирует, что клиническая проверка не проводилась. Статусная машина draft/published/retired готова для будущей модерации.
- Ресурсы поддержки сознательно НЕ заполнены выдуманными телефонами: экран честно говорит «нет проверенных ресурсов»; черновик RU (112) ждёт проверки владельцем.

## Доделано вторым заходом (коммит 0491f83)

- UI опор дня: создание из карточки практики («Сделать опорой дня») и со «Сегодня» («+ добавить опору»), отметка выполнения на месте.
- Отметка сна утром: карточка качества сна на «Сегодня».
- Вечерний режим: страница «Закрыть день тихо» (/app/evening) — выполненная мелочь, мысль на завтра (в дневник), ритуал; вечерняя карта на «Сегодня».
- Пауза перед скроллингом: отдельный сценарий (/app/scroll-pause) с выбором намерения и альтернативой.
- Сад: карточка растения — имя и перемещение по местам.
- Напоминания бота: настройки в «Я» (4 типа, по умолчанию выключены), воркер доставки в веб-процессе (локальное время, тишина ночью, блокировка бота), команды /start /app /help /stop (long polling).
- Экспорт данных (JSON) и удаление аккаунта (каскад, с подтверждением) — кнопки в «Я».
- Контентная админка /admin/content: статусы карточек, ресурсы помощи (черновик → публикация), обезличенная статистика, аудит.
- Тесты §32: elapsed таймера, конфликт редакций дневника, правила программ. Итого 329 бэкенд + 71 веб.
- Мультивариантная проверка initData + лог совпавшего варианта ([tg-initdata-ok] / [tg-initdata-mismatch]).

Осталось внешнее: подтверждение живого входа на устройстве владельца (см. логи), ИИ/аудио без ключей не подключены, редактор дней программ в админке — только API.
